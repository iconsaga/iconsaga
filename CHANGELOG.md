# Changelog

Every IconSaga release has a version number, so you can always see what changed. An icon that is out is never changed silently: when we redraw one, it gets a new version and the release notes say so.

- **New icons:** the middle number goes up (1.1.0 → 1.2.0).
- **Same icons, better search:** the last number goes up (1.0.0 → 1.0.1).
- **An icon removed or renamed:** the first number goes up. We avoid this.

See every icon at [iconsaga.com](https://iconsaga.com). Missing one? [Request an icon](https://github.com/iconsaga/iconsaga/issues/new?template=request-an-icon.yml).

## 1.2.0 · 2026-11-15

**One new icon: Logo Placeholder** (4,891 → 4,892 icons). A rounded logo slot with an abstract mark, for "pick a logo" or "your logo here" in slides and mock-ups. It is not any company's logo. Line, solid and duo, with motion (the mark pops in), names and search words in 10 languages ("logo", "brand mark", "โลโก้").

## 1.0.1 · 2026-11-15

**Better search, same icons.** No icon changed (the lock file lists the same 4,833 icons, versions and hashes as 1.0.0).

- Searching a plain word now finds the icon that is called exactly that first: *mail* → Envelope · *check* → Checkmark · *eye* → Visibility · *store* → Storefront · *close* → Cross Mark. An exact name in another language no longer comes before English names (English *chat* finds Chat Bubble, not the French word for cat).
- 43 new search words in English and Thai from real slide and video work: follow · split · org chart · calendar check · render · docx · glass · wifi · ติดตาม · ผังองค์กร · ไวไฟ …; repeated words tidied in all 10 languages.
- Icons that were already in the library and are now easy to find: drinking glass (Drinking Water) · plain fish (Whole Fish) · shrimp (Prawn) · ladybug (Ladybird) · piggy bank (Savings) · pencil (Edit) · .docx (Rich Text File) · calendar check (Availability Booked) · org chart (Site Map).
